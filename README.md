# TaCZ addon

知名枪械模组 TaCZ 的附属模组，主要提供枪械工作台、配件管理与战斗体验优化。

### 枪械工作台优化

- 支持按配件加成属性筛选配件。
- 材料显示简要信息，点击可跳转对应的 JEI 配方。
- 自动保存筛选、分类、页码与配方浏览位置。
- 按 SHIFT 批量制作，可在配置文件中调整制作次数。
- 可读取枪械工作台周围容器中的材料，兼容精妙背包与精妙存储。
- 显示当前页码和总页数。
- 制作成功后弹出 Toast，并显示实际制作数量。

### 配件管理优化

- 新增游戏规则 `liberateAttachment`，开启后可自由与枪械适用配件交互。
- 普通枪械改装界面可读取周围容器中的适用配件并直接安装。
- 可限制配件高级提示中展示的支持枪械数量。
- 新增游戏规则 `showAttachmentDetail`，可显示配件对当前手持枪械造成的详细属性变化。
- 增强配件属性 Tooltip，同时保留 TaCZ 原有提示内容。

### 其他

- 可指定完全作为近战武器使用的枪械，将开火动作替换为近战攻击。
- 支持换弹过程中直接开火。
- 按住 TAB 并滚动鼠标滚轮，可快速切换物品栏中的枪械。
- 可取消 TaCZ 切枪时的收枪后摇。
- 第三人称瞄准时自动切换第一人称，停止瞄准后恢复原视角。
- 在物品栏中对弹药盒按 SHIFT 并右键，可批量收集可用弹药。
- 在容器界面悬停枪械、弹药、弹药盒或配件时，可高亮相关物品。
- 精妙背包与 Curios 中的兼容弹药可参与弹药检测与实际消耗。

### 兼容性

- 基于 TaCZ 1.1.8-hotfix 制作。
- 兼容 JEI、精妙背包、精妙存储与 Curios。
- 第三人称瞄准兼容 Shoulder Surfing Reloaded 与 Leawind's Third Person。
