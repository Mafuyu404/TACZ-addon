# TaCZ addon

TaCZ 的玩法与交互增强附属。

## 枪械工作台

- 支持按配件加成属性筛选配件。
- 保存筛选、分类、页码与配方浏览位置。
- 材料可跳转对应 JEI 配方。
- 显示当前页码和总页数。
- 支持按 **Shift** 批量制作。
- 制作完成后显示实际制作数量 Toast。
- 枪械工作台可使用附近容器中的材料。

## 配件管理

- 新增游戏规则 `liberateAttachment`，允许不依赖玩家实际库存使用当前枪械可安装的配件。
- 普通改装界面可读取附近容器中的兼容配件并直接安装。
- 可限制配件 Tooltip 中显示的兼容枪械数量。
- 新增游戏规则 `showAttachmentDetail`，可显示配件对当前手持枪械造成的更详细数值变化。

## 射击与操作

- 支持**换弹过程中开火**。
- 可指定完全作为近战武器使用的枪械。
- 按住 **TAB** 并滚动鼠标滚轮，可在手持枪械与主物品栏其他枪械之间快速切换。
- 可取消 TaCZ 的切枪收起/拔出延迟。
- 第三人称瞄准时可自动临时切换为第一人称，停止瞄准后恢复原视角。
- 在玩家物品栏中对弹药盒 **Shift + 右键**，可批量收集可用弹药。

## 物品关系与界面

- 在容器界面悬停枪械、弹药、弹药盒或配件时，可高亮与其存在 TaCZ 使用关系的其他槽位。
- 可关闭物品关系高亮，或单独关闭其在 Sophisticated Backpacks / Sophisticated Storage 界面中的显示。
- 增强配件属性 Tooltip，同时保留 TaCZ 原有 Tooltip 内容。

## 可选模组兼容

- **JEI**：枪械工作台材料可跳转配方。
- **Curios**：Curios 槽位中的兼容弹药可参与 TaCZ 的弹药检测与消耗。
- **Sophisticated Backpacks / Sophisticated Storage**：
  - 玩家携带的背包可作为弹药来源，并参与 HUD 弹药统计与实际消耗。
  - 背包方块可作为附近枪械工作台材料源与配件来源。
- **Shoulder Surfing**：兼容瞄准时自动切换第一人称及视角恢复。
