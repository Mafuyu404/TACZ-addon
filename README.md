# TaCZ addon

知名枪械模组TaCZ的附属模组，功能如下：

### 枪械工作台优化

- 支持按配件加成属性筛选配件。

- 材料显示简要信息且点击跳转对应的JEI配方。

- 自动保存当前筛选、分类、页码与配方浏览位置并在下次打开时跳转。

- 按SHIFT批量制作，可在配置文件中调整制作次数。

- 可读取枪械工作台周围容器中的材料，兼容精妙背包与精妙存储。

- 显示当前页码和总页数。

- 制作后弹出Toast提醒，并显示实际制作数量。

### 配件管理优化

- 新增游戏规则liberateAttachment，开启后任何枪械可随意与所有适用的配件交互，而与玩家物品栏无关。

- 普通枪械改装界面可读取周围容器中的适用配件并直接安装。

- 可指定对配件按SHIFT时展示的支持枪械数量，避免遮挡屏幕与卡顿。

- 新增游戏规则showAttachmentDetail，开启后可显示配件对当前手持枪械造成的详细属性变化。

- 增强配件属性Tooltip，同时保留TaCZ原有的其他Tooltip内容。

### 其他

- 可在客户端配置文件中指定完全作为近战武器的枪械，这些枪械的开火动作将被替换为近战动作。

- 支持换弹时开火，仅在枪械仍有可立即发射的弹药时生效。

- 按住TAB并滚动鼠标滚轮，将手上的枪械切换为物品栏中其他枪械，此按键可配置。

- 可取消TaCZ切枪时的收枪后摇。

- 第三人称视角瞄准时，自动切换到第一人称瞄准，停止瞄准后恢复原视角。

- 在玩家物品栏中对弹药盒按SHIFT并右键，可批量收集可用弹药。

- 在容器界面悬停枪械、弹药、弹药盒或配件时，可高亮与其存在TaCZ使用关系的其他物品。

- 玩家携带的精妙背包可作为弹药来源，并参与HUD弹药统计与实际消耗。

- Curios槽位中的兼容弹药可参与TaCZ的弹药检测与消耗。

### 兼容性

- 本模组基于tacz-1.1.8-hotfix制作，暂无其他TaCZ版本兼容保证。

- JEI用于枪械工作台材料配方跳转。

- 兼容精妙背包与精妙存储，支持作为附近枪械工作台材料与改装配件来源；玩家携带的精妙背包还可作为弹药来源。

- 兼容Curios，可使用Curios槽位中的兼容弹药。

- 第三人称瞄准兼容Shoulder Surfing Reloaded与Leawind's Third Person。
